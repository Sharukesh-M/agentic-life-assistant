# JARVIX Frontend System

Frontend user interface application for **JARVIX – Goal-Aware Proactive Agentic AI Life Assistant**.

## Overview

The JARVIX frontend provides the interactive voice interface, goal planning dashboard, task management timelines, and proactive notification center.

Design specifications and component token standards are configured in [DESIGN.md](../DESIGN.md) and backed by the reference design systems in [references/ux-ui-agent-skills](../references/ux-ui-agent-skills).
